# XMRig Miner Add-on

Monero (XMR) CPU-Miner als Home Assistant Add-on.

## Konfiguration

| Option | Beschreibung |
|--------|-------------|
| `pool` | Mining Pool (Standard: supportxmr.com) |
| `wallet` | Deine XMR-Wallet-Adresse |
| `worker` | Worker-Name (frei wählbar) |
| `threads` | CPU-Threads (Pi 5 = max 4) |

## Installation

1. Repository in HA hinzufügen:
   `https://github.com/Axxaaxxaaxxa/Claude-blah-blah`
2. Add-on installieren
3. Wallet-Adresse eintragen
4. Starten

> ⚠️ Erster Start dauert ~30–60 Min (Build-Prozess)
